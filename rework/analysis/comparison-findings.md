# 参考与旧版诊断摘要

参考：1089 帧完整解码；旧成片：7543 帧完整解码。运动测量逐帧进行，排除参考水印区域与恒定边栏。另查看参考的 4fps 密集接触表，以及旧版所选 8 秒的 4fps 接触表。逐帧数值是辅助定位，不能替代艺术判断。

- 参考主要造型段 6–32s 的帧间变化中位比例约 4.28%；旧版所选段约 0.193%。旧版约 51% 的帧位变化比例不足 0.2%，其近四秒等字空场尤其明显。不同歌曲不能简单按数字追求同样切换频率。
- 旧版的结构性失败：长期固定画面重心、沿预留位置填字、人物与文字互不作用、贯穿顶栏/页脚消耗视觉空间、机械弹性和循环跳动、重复构图只换配色。
- 参考的有效特征：巨大字先占画面后让位、斜切对话空间、窗口侵入和升级、角色极近景与字体重新结合、字体尺度变化、遮挡转换和快推跟随。
- 新样片没有沿用每句一个 Stage + Window + Caption 模板。它用六种构图建立「欲望—贪心—请求—世界—广播」因果链。

所有原参考截图仅用于本地研究，未作为样片画面或随公开交付复制。
