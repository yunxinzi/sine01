# 实渲返工记录

## V1 / 240 帧完整 MP4

已经真实渲染，并查看运动接触表及逐秒视频关键帧。构图从旧版同一板式扩展为六种视点，但尚不接受 V1：

- 第 0 帧「很」的下部裁切过量，开场缩略图不完整；减少入场尺度和纵向偏移，角色落点也需稳定。
- 「全世界」镜头中「世」在演唱前露出顶边碎片，是离屏初始状态处理失误，不是有意的构图；改为到真实字头后才进入可见层。
- 面部特写 2.5–3.5s 有接近一秒的近静止；保留声乐长音的短停顿，但增加有目标的缓推和瞳孔心形在实测瞬态上的轻微跟随。

这些是视觉审查指出的问题，不以编译通过替代艺术判断。V2 将重新真实渲染，仅渲染 8 秒样片。

## V2 / 再次实渲与全 240 帧几何审查

「世」提前露出的碎片已消除，角色特写增加有目标的缓推。仍暂不接受：首帧「很」还有约 22px 的真实字形边界越界；「全」的旋转边界在落稳后过于贴顶（保守矩形审查也会包含空白角，但需要为字保留呼吸空间）。第三版进一步抬高开场字的基线、给「全」留边、稳定特写的边角字，并在「贪」「要」高速移动时加入按实际位移速度计算的横向拖曳模糊，静止时保持清晰。

## V3 / 提交样片审核

- 精确抽取第 0、30、60、90、120、150、180、210、239 帧，而不是把下采样的中点误当作整数秒。
- 另查看 23 个入场、接触、回弹、极近景跳切与界面接管帧。所有 240 帧另行解码，检查字体与几何。
- 六种主要构图在接触表中有明显区别；白底巨字、蓝白斜分、全屏面部、蓝底单字、斜向文字世界和全屏广播各有自己的尺度与重心。
- 原先接近四秒的等字空场已消除。长音保留可读停顿，但有欲望/面部视点推进；没有沿用原版每句同一标题栏、字幕胶囊和说明条。
- 「很」首帧完整，「全」落点留边，尚未演唱的「世」「界」不再提前漏入。30 个入画/回弹帧触发保守边界提醒，均为已经查看的有意运动或旋转空白角，不存在落稳后的持续裁切。
- 快速移动时的模糊由字的位移速度控制，落稳后清晰；没有用反复淡入淡出掩饰换景。
- 原参考片的水印、平台结尾、创作者信息及画面均未作为样片素材。

内部设计判断：V3 可交付为 8 秒方向验证样片，供用户判断视觉风格。技术检查不证明艺术质量，不声称经过人工逐字听审。此任务未重新制作或渲染全片；现有失败全片保留作基线。
